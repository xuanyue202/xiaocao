# 小草 Regime / Posture 时间线 (2026-06)

> **用途**：agent 每日盘前读**最新一条**定 posture（环境判断 + 仓位姿态）。
>
> **重要免责（"真实的谎言"标准）**：以下每一条都是小草**当时（盘前/盘后）**基于当时盘面的判断，**会过期**，且**未经真实行情验证**。
> - 这是"框架第一性原理对"，**不等于** backtest 对（见 `feedback_framework_design_vs_data.md`）。
> - 日后必须用真实行情对每条 `regime_call` + `what_would_falsify` 做**命中率回测**：分别统计他的 regime 判断、方向排序、龙头点名、时间轴的事后正确率。对他本人也要用**反"真实的谎言"标准**——警惕"avg 命中率↑ 但靠少数几条大判断撑起来"的集中度 trick，要看**逐条 + 跨子窗口一致性**，而非整体平均。
> - 区分两类信号：`timeless`（方法论/纪律，可长期复用）与 `dated`（当日方向/点名，次日即可能失效）。本表是 dated 判断的时间序列，仅作"他当时怎么想"的快照。
>
> **regime 取值**：`divergence`(分歧/趋势与短线背离) / `bear`(主跌) / `trend_strong`(趋势主升) / `trend_continuing`(趋势延续/轮涨)。同一天多场（盘前+盘后）取值可能不一致，下表已合并标注。
