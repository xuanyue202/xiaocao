# Cloud Discovery Coverage

Use this contract for hourly 吕晓彤 and 路西法 Netdisk discovery.

Discovery is coverage-led. An exact pending identity performs zero discovery.
The first baseline and Monday 03:00 topology audit are complete; ordinary
hourly sweeps read only structural/frontier directories, up to three hot roots,
new roots, and one deterministic rotating cold shard. Provider mtimes rank hot
roots but never prove absence.

For 吕晓彤, descend the single-wrapper chain
`/彤商学院防断更新zk7897897/彤商学院`, read each immediate category once, then
recurse only selected month/chat/report subtrees. For 路西法, read
`/课程/路西法全套` once and recurse only selected top-level course roots.

Persist `direct_roots` and `recursive_roots`; only covered paths may change
presence. Unscanned historical paths retain their durable state, while a
missing covered directory removes its subtree. Partial coverage never claims
global absence.
