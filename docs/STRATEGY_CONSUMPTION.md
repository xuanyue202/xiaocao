## Important WHY at the seam

- Ordinary COLD remains a gate. Only explicit cited/reviewed Xiaocao v2 named-mode
  follow can restore COLD within original frozen candidates; UNKNOWN mode and all
  account/capital/market/claim constraints remain. General focus is not an order.
- Primary APP excludes688/689 before selecting seats, then scans qualified original
  ranks so account permission does not waste a legitimate slot. This does not
  change Paper/funded rules or prove yesterday's rejected order.
- Paper first-minute HIGH is an intentionally adverse cost benchmark. A later day
  HIGH, point maximum or VWAP cannot certify the minute; lowering cost changes
  the experiment. Missing proof is source failure, not ordinary no-buy.
- Source reuse clock, quote clock, viewpoint validity, policy expiry and native
  evidence age are different contracts. A single generic freshness TTL is unsafe.
- Funding is not profit; pending cash is not an economic loss. Qualified current
  cash/owned marks/risk may coexist with unknown final fees/PnL. No invented NAV,
  automatic cash classification, reset high-water/pause or manual-lot absorption.
- Old service uncertainty stays on its original claim. It does not by itself prove
  today's whole account unusable; §1e requires real current affected scope. The
  bounded isolation executor is still an implementation gap, not a prompt waiver.
- Soft exit deferral avoids sparse morning-low liquidation; hard/protective exits
  retain actual permissions. Use current closing launcher/exit_policy timing,
  not a historical14:55 sentence or new research feature.
- Pre~2024-05-13 concept-rank returns are zero-filled. Rank history is not return
  history; stock-level returns or proved later panels are required for that research.
- Valid no-trade is an observation; engineer-missed execution is missing data.
  Evaluate whole opportunity funnels and independently comparable trades, not
  report counts, daily-return rows or only successful runs.
