## 一、道 — 环境 / posture 判断(先定 regime,再谈做不做)

先问"市场处在什么阶段",**不要先问"今天买什么"**(0413-A)。判断顺序:大盘看分歧,板块看主线,个股看排名,买卖看强弱变化。

- **趋势 vs 短线是两套独立体系** `[先验]`。"趋势跟短线没关系";短线评分差不做短线,趋势线仍可做。不要做"二极管"机械空仓(06-01)。
- **regime 分层**:`trend_strong/continuing`(趋势主导,进攻持有)· `divergence`(分歧/轮动,防守观望)· `bear`(主跌,空仓)。`[先验]`
- **空仓只对「持续性」主跌,不对单日/数日回调** `[校准 2026-06-23]`。判断校准 loop(`posture_calibration.py --decompose`,大票市场 2021-2026)实测:防守/空仓 posture 在**连续坏 1-3 天 26-32% 命中、4-10 天 25-34%(都是错的——回调会反弹)**,只有**连续恶化 >10 天才校准(67-83% 命中,n=6 小样本)**。=> **别对回调空仓(踏空反弹),空仓留给「持续 >10 天」的真主跌**(=小草 2023 被收割的纪律的精确版,也呼应「不做二极管机械空仓」)。进攻 posture(趋势强时持有)基线 61% 命中、是对的。判断先验校准,非脊柱参数;forward 继续验证 n。
- **环境管仓位,方向富三代,模式问收益** `[先验]`(06-18 口令)。环境差→轻仓"打麻将";总体分<60 或短期为负→第一类人通通不碰(06-21)。
- **短线环境恶化沿涨停板高度扩散**:10cm 没赚钱→20cm→科创板,扩散完=系统性转空(06-01)。`[待验]`
- **大小票黄白线背离**(大票白线跌/小票黄线涨,或反之)=资金不聚焦、跷跷板,**当日涨跌不可预测**,降短线、重趋势(06-10/06-12/06-18)。`[先验]`
- **判主线生死用"行业轮动频率"**:某板块轮动频率高=主线在(今天不轮明天轮);掉出前列被新材料/有色顶上(即便指数还横盘)=主线走弱(06-18)。`[待验]`
- **趋势阶段框架**:加速→共振→扩散;**"扩散/普涨"是见顶前兆**,普涨一般不延续两天,第三天加速就直接走(06-02/06-21)。`[待验]`
- **好股票=赚钱地方的股票**;没赚钱效应处没有好股票,先确认有赚钱的地方再排名(06-01/06-08)。`[先验]`

## 二、法 — 选股

### 主线连续性
- **看中军/核心大票,不看杂毛**:一个方向是不是主线,看它的中军和核心大票能否在分歧里站住,不看有多少小票乱涨(0413-A)。`[先验]`
- **强弱排序**:主线中军 > 主线大票 > 弱转强核心票 > 排名前排票 > 后排补涨票(0413-A)。`[先验]`
- **从哪里开始从哪里结束**:二波启动资金回原主线;别追超跌反弹领涨(无延续性)(06-10/06-15)。`[先验]`
- **大票单独排名**(big-ones):趋势大票按市值/强度单独挑,平铺 2-3 只最强、不纠结切哪只(06-03/06-16)。`[已编码]` `pick_big_ones` (rules.py)

### 低位卡位(买点不追高)
- **红盘起爆**:算法高分(jssb)但价格未拉,刚转红、涨幅 0-4%(主攻)/0-3%(方向共振)买入,过滤已涨停/绿盘(0419)。`[已编码]` `check_qibao` (rules.py),pct∈(0,4] / (0,3]
- **方向低位低吸 / 绿盘低吸前3名**:方向内排名前3 + 低位/绿断 + 竞王达标(0413)。`[已编码]` `check_dixi` / `check_direction_dixi`
- **盘中起爆+当日方向第一名共振**:9:31 取排名第1/2名、分≥10、方向匹配(优先电子);跨方向(如建材)剔除(06-15/06-17/06-18)。`[已编码]` 方向共振逻辑在 `_direction_obj` / DIRECTION_DISCOUNT

### 弱转强 / 连板
- **弱转强 + 排名 + 主线 + 大票**四要素(0413-A)。`[先验]`
- **连板**:接力/连板核心 xcjw≥阈值,方向支持打折(0412)。`[已编码]` `check_lianban`
- **方向模式=做昨天没大涨的方向**:只取前2-3名里昨日涨幅低(≤2%)、当日排名靠前者(06-03/06-15)。`[待验]`
- **轮涨阶段不做去弱留强**:今天强明天弱、弱明天强,切来切去两头挨打;待在主线平铺持有(06-18,金安国际"弱了又涨回来"为证)。`[待验]`

## 三、术 — 时间窗 / 买点 / 节奏

- **9:31-9:35 黄金窗**:排名上来但涨幅还不高的(0419);9:30:30 后更稳(开盘头十几秒巨幅波动易误判)(06-21)。`[已编码]` `MORNING_REVIEW_TIME=9:35` (exit_policy.py)
- **买点 0-1% / 低位卡位**:不追高;趋势股回调低吸,绝不在快涨停/接近高点追(06-10"等涨上去再追=错误心态")。`[已编码]` 起爆 pct 上限 4%/3%
- **下杀低吸**:9:35 前(放宽 9:45)在模式内下跌第一个拐点低吸,优于开盘价直接买(06-17/06-21)。`[待验]`
- **预警时效**:9:45 前最好,10 点后弱;全新概念晚预警仍可能有效(06-17)。`[先验]`
- **日内节奏(仅参考,背离日失效)**:常见上午约 10:00 高点、11:00-11:15 低点、下午约 14:00 反弹;跷跷板/单边日不可猜(06-01/06-10)。`[先验]`
- **金字塔加仓**:只在回调加,后一笔<前一笔;短线少加(06-15)。`[先验]`

## 四、纪律 — 出场(为什么不卖 / 分批 / 方向还在就扛 / 卖点后移)

- **方向还在就扛**:趋势没结束,跌下去是低吸点不是卖点;"你在趋势里赚钱为什么要动它"(06-16/06-21,圣阳类反复问"能不能持有"→方向在就持有)。`[已编码]` `strong_hold_reason` 强持有抑制(NEAR_LIMIT_UP / LIMIT_UP_DAY / TURNED_LEADER_NEAR_HIGH / STRONG_TREND_HOLD)
- **卖点后移到 14:55,盘中只执行硬地板**:盘中检查点只 EXECUTE HARD_STOP,普通 trailing/composite 恶化是 DIAGNOSE(deferred),14:55 纪律 pass 才执行——否则稀疏检查点把 2% trailing 变成"卖 D+1 早盘低点"(decompose_pnl 验证)。`[已编码]` staged exit / `EOD_DISCIPLINE_TIME=14:55`
- **硬止损 8%**:catastrophic 才盘中砍,且强持有时不触发(限价跌停无买盘 LIMIT_DOWN_NO_BID 单独 block)。`[已编码]` `HARD_STOP` dd≥8% & not soft_hold;`sell_block_reason`
- **卖趋势不必等破位**:趋势"不再领涨、形成轮动"就准备卖,在高点减最舒服(06-01)。`[先验]`
- **分批 / 怕卖飞就减1/3**:不一次清,强的少减、弱的换掉;回调后大概率修复再减(06-01/06-02)。`[先验]`
- **不参与横盘**:横盘可能不 A 杀直接腰斩(宁德 215→134、40%);出现核心阴线/破结构就在反弹出,不赌横盘(06-02/06-05/06-08/06-14)。`[待验]`
- **核心阴线后大概率次日修复反弹再走**:不在阴线当天恐慌割(06-05 中际旭创放量阴线)。`[待验]`
- **大票不 A 杀但会横盘**:外盘大跌只影响低开,低开后大概率修复;修复弱就反弹离场(06-07/06-08)。`[先验]`
- **东方不败仓位法**:每亏总资金 10% 砍半总仓降级,每赚 20% 升一级;亏损时减仓不加码(06-18/06-21)。`[待验]`
- **会卖才是师傅是骗子话术**:买在低位卡位 + 跟随结构离场,不靠复杂卖点(06-21)。`[先验]`

## 五、实时盘面判断模型(How he reads the tape live)

> 给 agent 做**实时分诊**用,不是事后结论。观察→推断→底层逻辑→动作。覆盖 盘前 / 集合竞价 / 开盘9:31-9:35 / 盘中。

### 盘前 (pre-open)
| if 观察 | then 推断 | 底层逻辑 | 动作 | 状态 |
|---|---|---|---|---|
| 普遍高开(尤其外盘隔夜大涨驱动) | 易高开低走 | 普涨缺分歧承接 | 别急追,等开盘消化(06-12/06-16) | `[先验]` |
| 普遍低开(跟随美股) | 正常,9:25 前常修复一部分 | 外因低开≠主线坏 | 不在最低点割,等竞价修复(06-08/06-18) | `[先验]` |
| 昨日领涨板块今早低开走弱 | 昨涨今跌轮动 | 缺分歧承接易回落 | 回避追昨日强板,布局昨日滞涨主线(06-10) | `[待验]` |
| 运线/竞价评分不够(负分)+清仓环境 | 短线严格不做 | 评分门槛是硬纪律 | 只守趋势,有些钱不赚(06-10/06-12) | `[先验]` |

### 集合竞价 (auction)
| if 观察 | then 推断 | 底层逻辑 | 动作 | 状态 |
|---|---|---|---|---|
| 普遍低开但 9:25 前修复 | 恐慌已定价大半 | 竞价末段修复极端低开 | 按修复路径而非崩盘路径处理(06-08) | `[待验]` |
| 开盘跌停板,但跌的不是你主线板块 | 对趋势仓无伤 | 利空只砸短线/业绩差票 | 趋势仓不动,盯主线内个股能否修复(06-18) | `[先验]` |
| 普涨高开把短线评分顶成正分 | 假信号 | 背离/无主线时正分无效 | 不因评分转正进场(06-12) | `[先验]` |
| 竞价高开后段分歧 | 高开易低走,属正常 | 分歧≠方向坏 | 回调没问题,不动摇(06-15) | `[先验]` |

### 开盘 9:31-9:35
| if 观察 | then 推断 | 底层逻辑 | 动作 | 状态 |
|---|---|---|---|---|
| 开盘大小票一致 | 趋势大票最好卖出时机 | 一旦背离趋势修复只是卖点 | 趋势减仓在开盘修复段冲高分批(06-02) | `[先验]` |
| 前一日领涨方向开盘不退反强 | 主线延续 | 黄金窗看分化 | 重点跟该龙头板块;变弱方向剔除(06-15) | `[先验]` |
| 预警/排名集中某一行业(如9:30:06全是电子) | 当天主线就是它 | 集中度=确定性 | 直接跟随,在该行业内选票(06-18) | `[已编码]` 方向共振 |
| 选中票 9:35 前跌破当时涨幅(下杀盈亏) | 资金自救型回踩 | 盘中模式选有议价的大资金组合 | 第一个拐点低吸,不追开盘价(06-17/06-21) | `[待验]` |
| 排名靠前但属跨方向(如建材) | 是"面" | 方向过滤排除 | 剔除,只取主线方向内(06-15) | `[已编码]` |
| 不及预期(本该冲高却高开即回落) | 偏弱 | 开盘第一时间是卖点 | 开盘走或至少走一半(06-12 昊华) | `[先验]` |

### 盘中 (intraday)
| if 观察 | then 推断 | 底层逻辑 | 动作 | 状态 |
|---|---|---|---|---|
| 指数白线(大票)跌、黄线(小票)涨 | 资金不聚焦大票 | 跷跷板,资金分散 | 趋势仓信心下调/短线不做(06-10/06-12) | `[先验]` |
| 指数跳水但主线板块预警持续/加强 | 资金仍在聚焦该方向 | 逆势增强=扛得住 | 持股不卖不慌(06-16) | `[待验]` |
| 下跌家数随时间单调扩大(平→3700→4600) | 趋势性回落实时确认 | 广度恶化 | 任何反弹当减仓窗口,不抢反弹(06-02) | `[先验]` |
| 指数涨但跌>4000家、大小票分化 | 资金聚焦大票=机构行为 | 4000亿非散户能为 | 只看趋势站大票,回避小票短线(06-16) | `[先验]` |
| 领涨全是超跌/杂乱低位板块 | 弱势垃圾反抽 | 无主流资金合力 | 回避,只认有持续性主线(06-10) | `[先验]` |
| 趋势龙头盘中分歧/回落(主线未变) | 新上车点非走坏 | 回调是趋势常态 | 回落低吸/持有,不恐慌割(06-16) | `[已编码]` 强持有抑制 |
| 板块内高低切(高标横盘+低标补涨) | 趋势延续健康形态 | 资金没出板块 | 持有不动,不去弱留强(06-17) | `[待验]` |
| 板块外高低切(银行/保险/AI软件走强且趋势同时变弱) | 主线可能离场信号 | 资金真离开主线 | 警惕减仓/反弹离场(06-08/06-21) | `[待验]` |
| 跷跷板/指数互相背离 | 高低点不可猜 | 人心是反的 | 放弃方向下注、空仓,不据猜测高点减(06-12/06-18) | `[先验]` |
| 连续加速/一蹴而就 | 接近卖点窗口 | 加速=终局信号 | 严格观察、不加仓、准备离场(06-17/06-21) | `[待验]` |
| 单只逆势跳水后回落 | 被动跳水属正常 | 主动暴跌(最强变最弱)才不可买 | 被动且仍最强=买点;主动=卖(06-03) | `[先验]` |

## 六、给 agent 的最小决策序(daily checklist)

1. **先定 regime**(道):趋势主导 / 分歧轮动 / 主跌空仓 → 决定仓位与做不做短线。
2. **找主线**(法):中军/大票能否站住;轮动频率指向哪;是否"从哪开始从哪结束"。
3. **若做,低位卡位**(术):9:31-9:35 窗、买点 0-1%、不追高、下杀低吸。
4. **持仓出场**(纪律):方向还在就扛 `[已编码]`;盘中只执行 8% 硬地板 `[已编码]`;普通恶化 14:55 执行 `[已编码]`;不参与横盘/分批/卖点后移为 `[待验]/[先验]`,**仅 agent 叙述判断,不自动改回路**。
