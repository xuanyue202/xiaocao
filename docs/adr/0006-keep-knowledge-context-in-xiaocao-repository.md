# Keep the Xiaocao knowledge context in the Xiaocao repository

Xiaocao keeps governed evidence, distillations, candidate hypotheses, research protocols, and verdicts in the existing project knowledge context rather than creating a separate knowledge repository or placing them under behavioral source code. Co-versioning lets research inputs, gates, and consuming code remain reproducible across machines, while published KOL reports and longitudinal records remain authoritative in 灰常亮 and are consumed through read models; any local mirror is a rebuildable cache, not a second truth. Private raw evidence, household state, credentials, and runtime ledgers are excluded from a public Git boundary and require a private repository or private evidence store.
