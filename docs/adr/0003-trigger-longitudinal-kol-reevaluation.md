# Re-evaluate longitudinal KOL viewpoints only on explicit triggers

The 7×24 coordinator maintains each KOL's current-viewpoint projection through targeted re-evaluation triggered by a new publication event, a due horizon/trigger/falsifier, material related market or fundamental evidence, or a user refresh request. It does not periodically recompute all history, and an evaluation-only update appends evidence to 灰常亮 without creating a synthetic report, Enterprise WeChat reminder, or Book KOL-US action; this keeps currentness explicit without turning absence of contrary evidence into automatic renewal.
