# Make Book T theme-first and multi-source

Book T will allocate paper risk by theme rather than by security and will consume a frozen, evidence-bound judgment snapshot in which Xiaocao supplies phase and timing, Lv Xiaotong's 马车 supplies a short-lived priority theme pool, other KOLs supply confirmation, conflict, falsification, or new-theme proposals, and market facts retain final eligibility authority. A separate resolver chooses an ETF, a core trend stock, or an evidence-supported combination to express each theme; the deterministic spine alone owns selection constraints, fills, positions, exits, paired switches, and the ledger. This rejects both author-specific keyword patches and opaque weighted KOL voting: they are easy to add but cannot represent time horizons, conflicting roles, common theme risk, or unresolved instrument mappings safely.
